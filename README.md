# Tic Tac Toe Game
A simple and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript.

## Features
- Two-player gameplay (O and X).
- Automatic winner detection.
- Draw condition detection.
- New Game option.
- Reset Game option.
- Prevents further moves after the game ends.

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Play
1. Open the game in your browser.
2. Player O starts the game.
3. Players take turns marking the boxes.
4. The first player to get three marks in a row, column, or diagonal wins.
5. If all boxes are filled without a winner, the game ends in a draw.
